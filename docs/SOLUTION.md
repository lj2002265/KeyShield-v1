# 方案链接与阅读说明

## 可提交的入口

- [完整交付发布页](https://github.com/lj2002265/KeyShield-v1/releases/tag/v1.0.1)
- [方案书与使用说明 PDF](https://github.com/lj2002265/KeyShield-v1/releases/download/v1.0.1/KeyShield-Proposal-v1.0.pdf)
- [源码仓库](https://github.com/lj2002265/KeyShield-v1)
- [安装说明](INSTALL.md)

方案书为 18 页 PDF，约 1.2 万汉字，包含选题背景、场景需求、总体架构、技术选型、角色和工作流、调度和循环机制、结果验证、代码模块、四张真实系统截图、测试与性能、人工智能使用说明。

方案书的业务基线是已发布的 v1.0.0（原版服务端内部版本 v3.3）。v1.0.1 增加 Windows 安装器、便携 Demo、启动与交付说明，并调整自检脚本以支持独立数据目录；核心业务代码保持不变。因此方案中的业务说明仍适用，最新安装操作以 INSTALL.md 为准。

## 评审复现方式

先阅读方案书，再根据电脑环境选择 Windows 安装包、便携 Demo 或源码 Demo。启动本地程序后按 DEMO.md 演示；需要验证结果时执行隔离自检。所有下载地址均为公开 GitHub 资产，评审不需要你的 GitHub 账号或原开发数据库。

本项目没有在本次交付中新增公网在线服务。方案 PDF 链接和下载链接可以直接分享；127.0.0.1 地址需要在评审本机运行后使用，不能作为远程在线演示链接。

## 能力与证据范围

第一版已实现个人保险箱、组织与团队托管、成员授权、模型代理、虚拟 Key 和审计；没有实现自主规划与循环反思的 Agent，也没有运行中的 RAG 或 MCP。文档对尚未实现的方向明确标记为后续设计。

方案书的本机性能数据不代表公网容量或模型生成速度；自动化检查不等同于独立渗透测试。正式服务上线需额外验证域名、HTTPS、邮件、备份和真实厂商调用。完整说明见方案书第七、八章。
